# ajeya02.github.io

Personal academic website, styled after [jonbarron.info](https://jonbarron.info/). Plain HTML + CSS, no build step.

- Edit `index.html` for content, `style.css` for styling.
- Profile photo: `images/profile.jpg`. Thumbnail clips live in `images/`.
- Preview locally: `python3 -m http.server` then open http://localhost:8000.
- Pushing to `main` redeploys via GitHub Pages.
